# @dsh-external/dsh-mastery-loop — 精通闭环学习系统

让大学生在短时间内掌握**任何一门科目**的学习系统插件。源自抖音「理科学习 Skill」
方法论（识别考点→拆解条件→建立模型→选择方法→复盘错误），取其精华、去其糟粕、
泛化创新为科目无关的 **Mastery Loop** 七步闭环。

## 核心理念

> 学习失败不是因为不努力，而是没有一套正确的学习系统。
> 刷题不是堆数量，而是把每道题变成**可复用的思维模板**、把每个知识点变成**知识图谱的节点**。

## 七步闭环（Mastery Loop）

| 步骤 | 工具 | 作用 |
|---|---|---|
| 1 定位 | `study_orient` | 建立知识地图：考点/权重/考核方式/先修依赖/自检题 |
| 2 拆解 | `study_deconstruct` | 结构化拆解问题：条件/结论/隐藏信息/可用模型/入口信号 |
| 3 建模 | `study_model` | 生成思维模板卡片：入口/关键转折/易错点/识别信号/通用步骤/费曼一句 |
| 4 诊断 | `study_diagnose` | 错误归因四类：知识缺失/方法错误/审题偏差/执行失误 + 对症方案 |
| 5 迁移 | `study_transfer` | 变式训练：换条件/换情境/提难度 + 多题一解归纳 |
| 6 复盘 | `study_review` | 复盘模板 + 间隔重复排期（1/3/7/21 天）+ 主动回忆测试 |
| 7 路径 | `study_path` | 学习路径：目标→阶段→每日任务→里程碑自测 |

插件同时注入系统提示（`mastery-loop:method`），让模型在任何科目对话中自动按闭环工作。

## 铁律

- **不直接给答案**：先让学生暴露思考过程，再诊断纠正。
- **不堆刷题**：每道题必须提炼成模板，杜绝「记答案式」刷题。
- **可验证**：掌握 = 能独立做对 + 能讲清，而非「听懂了」。
- **科目无关**：数学/物理/编程/文科/医学/考证通用——「题」= 该科目的问题单元。

## 使用方法

安装后直接在对话中提问即可，模型会自动调用闭环工具：

```
帮我用精通闭环学习《数据结构》的二叉树，目标：两周掌握
这道题我卡住了……（贴题目）
我这样做对不对……（贴作答，模型会先归因再讲解）
学完了，帮我复盘一下并排复习计划
```

## 配置

| 配置项 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `anchorFirstTurn` | boolean | true | 首轮锚定：首轮只暴露 `study_orient`，首个工具调用后解锁全部（省首轮 prefill） |

## 构建与注入

```bash
DSH_CHECKOUT=<checkout> bash scripts/build.sh
# 注入器环境内：dev_inject_plugin <本目录>
```

## 设计来源

- 抖音「理科学习 Skill」（SenmuuuuW）：五步有效学习 + 高手刷题四问（入口/转折/易错/识别）
- **去糟粕**：科目局限（只适合理科）、孤立讲题（无记忆层）、无验证闭环
- **创新**：科目无关泛化、错误归因分类、间隔重复排期、知识图谱节点观、里程碑可验证、首轮锚定性能优化
